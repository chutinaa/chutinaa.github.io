⑤ How it is built behind this demo

  • Pure front-end: single-file HTML, zero dependencies, works offline.
  • Seeded random data: every run is reproducible; the numbers look real and are all fictitious.
  • Definition A/B switch: shows how the statistical rule changes the result; tables and chart recompute together.
  • Cross-checks: every table is recomputed independently; any mismatch flags red at once.
  • Email output: the SVG chart converts to PNG and embeds via cid into the .eml; opened in a mail client it is a ready-to-send draft.
Definitions: by first-decision month = a request belongs to the month it was first processed; a first rejection counts as that month's failure, and unprocessed requests stay out of the denominator.
